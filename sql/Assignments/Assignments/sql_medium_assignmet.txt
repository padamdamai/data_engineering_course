1.) Grab Rider – Third Completed Ride (Asked in Grab)

Grab wants to analyze how quickly users become frequent riders.

Given a table that records completed rides, write a SQL query to find each user’s third completed ride.

If a user has multiple rides on the same day, the ride with the smaller ride_id should be considered earlier.

Only include users who have completed at least three rides.

Table: grab_rides

+------------------+----------+
| ride_id          | INTEGER  |
| user_id          | INTEGER  |
| ride_date        | DATE     |
| ride_status      | STRING   |
+------------------+----------+

•	ride_status can be 'COMPLETED', 'CANCELLED', 'FAILED'
•	Only COMPLETED rides should be considered


Example Input:

+---------+---------+------------+-------------+
| ride_id | user_id | ride_date  | ride_status |
+---------+---------+------------+-------------+
| 201     | 1       | 2024-01-01 | COMPLETED   |

| 203     | 1       | 2024-01-05 | COMPLETED   |

| 208     | 3       | 2024-01-15 | COMPLETED   |
| 209     | 3       | 2024-01-18 | COMPLETED   |
+---------+---------+------------+-------------+


Example Output:

+---------+---------+------------+
| user_id | ride_id | ride_date  |
+---------+---------+------------+
| 1       | 204     | 2024-01-10 |
| 2       | 207     | 2024-01-20 |
+---------+---------+------------+

Explanation:

User 1 (COMPLETED rides only):
	•	201 → 2024-01-01

	•	206 → 2024-01-03

	•	207 → 2024-01-20 (3rd ride)
